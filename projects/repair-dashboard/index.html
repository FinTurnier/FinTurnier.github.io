Repair Dashboard

Web application for tracking engine repairs and parts, improved iteratively against customer requirements to help ensure on-time engine delivery.

  • Full-Stack Web
  • SQL
  • Cloud Migration

Overview

The Repair Dashboard is a production web application used to track engine repairs and parts through the maintenance, repair, and overhaul process. I implemented customer-requested changes that improved how teams track and ensure the delivery of customer engines.

Role

Senior Software Engineer on the Methods & Tools full-stack development team — responsible for building, maintaining, and improving the application in production.

Highlights

  • Implemented customer-driven feature changes end to end.
  • Contributed to migrating in-production digital MRO tools to AWS.
  • Produced a turnaround-time monitoring method (tracking incoming, approved, and outgoing tasks) that gave the operation a measurable performance signal.

Status

Proprietary system; this page describes the work at a high level. A technical write-up of the generalizable patterns (without sensitive detail) is planned as a note.
