Flight Planning Management System

A flight planning system in C# for managing flight routes in air traffic control, built through a full software development process.

  • C#
  • Software Engineering Process
  • Systems Design

Overview

Designed and built a flight planning management system in C#, allowing a user to manage flight routes in an air traffic control context.

Approach

The course applied the full software development process — requirements, design, implementation, and verification — rather than jumping straight to code. That discipline felt slow at the time. It scales better than heroic effort, and I kept relearning that lesson in professional work.
