Project · Pratt & Whitney

Validation Report Automation

Programs that automate daily engine test data collection and produce reports highlighting engine health and fleet status.

  • Python
  • Data Pipelines
  • Automation
  • Reporting

Overview

Manual collection and reporting of daily engine test data was slow and error-prone. I developed programs to automate the process end to end: gather the day’s test data, synthesize the relevant parameters, and generate a report that highlights engine health and fleet status.

Highlights

  • Replaced a manual daily reporting workflow with an automated pipeline.
  • Surfaced engine-health indicators directly, so the engineering team spent its time on the answer instead of the gathering.
  • Extended the same ad-hoc scripting approach I built as a thermal systems analyst into the software engineering role.

Lessons carried forward

Automating the report is only half the win — the other half is deciding which parameters actually belong in front of a decision-maker. See the related entry in Lessons.
